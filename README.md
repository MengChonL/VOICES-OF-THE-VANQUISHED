# GESB2008 歷史互動遊戲

## 關於這個遊戲

這是一個以拉丁美洲歷史為背景的文字冒險遊戲。在遊戲中，你將扮演四位不同的歷史人物，體驗他們在西班牙殖民時期的真實故事和艱難抉擇。

### 四位主角

- **波波卡 (Popoca)** - 阿茲特克羽毛工匠，見證特諾奇提特蘭的陷落
- **卡爾帕 (Kallpa)** - 安第斯山區牧民，經歷印加帝國的崩潰
- **瓜妮 (Guani)** - 泰諾農藝師，面對西班牙殖民者的入侵
- **巴拉姆 (B'alam)** - 馬雅商人，在新舊世界之間掙扎求存

每個角色都有三條不同的命運線，你的選擇將決定他們的結局。

## 如何下載和運行遊戲

### 第一步：下載項目

1. **點擊綠色的 "Code" 按鈕**（在 GitHub 頁面右上方）
2. **選擇 "Download ZIP"**
3. **解壓縮下載的文件**到你的電腦桌面或任何你喜歡的位置

---

## 第二步：一鍵啟動遊戲

我們已經為你準備好了自動安裝和啟動腳本，不需要任何編程知識！

### Mac 用戶

1. **找到文件 `VOICES-OF-THE-VANQUISHED` **
2.. 左鍵新增位於資料夾位置的終端機分頁
3.. 輸入 ./setup.sh

**就這樣！** 腳本會自動：
- 檢查並安裝 Node.js（如需要）
- 安裝遊戲所需的組件
- 啟動遊戲
- 在瀏覽器中打開遊戲界面

---

### Windows 用戶

1. **找到文件夾中的 `setup.bat` 文件**
2. **雙擊 `setup.bat`**
3. 如果系統詢問，選擇「是」以允許程序運行

**完成！** 腳本會自動處理一切，然後在瀏覽器打開遊戲。

---

### Linux 用戶

1. **打開終端機（Terminal）**
2. **進入項目目錄**：
   ```bash
   cd 你解壓縮的文件夾路徑
   ```
3. **運行安裝腳本**：
   ```bash
   ./setup.sh
   ```

 **搞定！** 遊戲會自動啟動。

## 常見問題

### Q1: 我完全不懂編程，可以玩這個遊戲嗎？
**A:** 可以！只需要雙擊對應的腳本文件，等待幾分鐘，遊戲就會自動啟動。

### Q2: 什麼是 Node.js？我需要自己安裝嗎？
**A:** Node.js 是運行遊戲所需的程序。**不用擔心**，我們的腳本會自動檢測，如果你沒有安裝，它會詢問你是否要自動安裝。

### Q3: 安裝腳本會修改我的電腦嗎？
**A:** 腳本只會安裝遊戲運行所需的 Node.js 和遊戲組件，不會影響你電腦的其他部分。

### Q4: 我雙擊腳本後沒有反應怎麼辦？

**Mac 用戶：**
- 右鍵點擊 `setup.command`
- 選擇「打開方式」→「終端機」

**Windows 用戶：**
- 以管理員身份運行 `setup.bat`（右鍵 → 以管理員身份運行）

### Q5: 如何停止遊戲？
**A:** 在運行腳本的窗口中按 `Ctrl + C`，或直接關閉終端窗口。

### Q6: 下次想玩遊戲怎麼辦？
**A:** 有兩種方式：

**方式 1（推薦）：** 再次雙擊 `setup.command`（Mac）或 `setup.bat`（Windows）

**方式 2（更快）：** 打開終端，進入項目的 `text-game` 文件夾，運行：
```bash
npm start
```

### Q7: 遊戲需要網絡連接嗎？
**A:** 
- **首次安裝**：需要網絡（下載組件）
- **遊玩遊戲**：不需要網絡（可離線遊玩）

## 遊戲操作

- **選擇角色**：在主畫面點擊你想扮演的角色
- **閱讀故事**：點擊「繼續」按鈕推進劇情
- **做出選擇**：在關鍵時刻選擇不同的道路
- **返回**：可以使用「上一個」按鈕回到之前的對話
- **重新開始**：隨時可以重新選擇角色或重玩故事
