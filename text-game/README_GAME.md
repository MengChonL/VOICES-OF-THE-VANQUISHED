# 被遺忘的聲音 - 文字冒險遊戲

一個關於信仰崩潰、文明衝突與生存抉擇的互動式文字冒險遊戲

## 🎮 遊戲簡介

這是一款基於歷史的文字冒險遊戲，講述了四位來自不同美洲原住民文明的角色，在歐洲殖民時期面臨的信仰崩潰和生存抉擇。

**時代背景：** 1490 - 1562

## 👥 可選角色

### 1. 波波卡 (Popoca) - 阿茲特克羽毛工匠 🪶
- **地點：** 特諾奇提特蘭 (Tenochtitlan)
- **時期：** c. 1519-1521
- **特點：** 備受尊敬的羽毛工匠，為皇帝和戰士製作神聖的儀式披風

### 2. Kallpa (卡爾帕) - 安第斯山區村民 🦙
- **地點：** 安第斯山脈
- **時期：** c. 1526-1533
- **特點：** 年輕的牧民，生活在世界屋脊，依靠互惠原則（Ayni）生存

### 3. Guani (瓜妮) - 泰諾農藝師 🌿
- **地點：** Quisqueya（伊斯帕尼奧拉島）
- **時期：** c. 1490-1508
- **特點：** 木薯處理大師，酋長的妹妹，在母系社會中地位崇高

### 4. B'alam (巴拉姆) - 馬雅可可商人 🍫
- **地點：** 猶加敦半島
- **時期：** c. 1520-1562
- **特點：** 精明的商人，在分裂的城邦間經營貿易

## 🎯 遊戲特色

- **多重視角：** 體驗四位不同角色的獨特故事
- **三條路線：** 每個角色都有三條不同的命運線可以選擇
- **歷史真實：** 基於詳實的歷史研究和參考文獻
- **沉浸式體驗：** 豐富的對白、內心獨白和情感描述
- **精美UI：** 現代化的用戶界面設計，支持中文

## 🚀 如何開始

### 安裝和運行

1. 確保已安裝 Node.js（建議 v14 或更高版本）

2. 進入遊戲目錄：
```bash
cd text-game
```

3. 安裝依賴（首次運行）：
```bash
npm install
```

4. 啟動遊戲：
```bash
npm start
```

5. 遊戲將在瀏覽器中自動打開（通常是 http://localhost:3000）

## 🎲 遊戲玩法

1. **開始畫面：** 點擊「開始遊戲」進入角色選擇
2. **選擇角色：** 點擊任意角色卡片查看詳細介紹並選擇
3. **閱讀劇情：** 通過點擊「繼續」按鈕推進故事
4. **做出抉擇：** 在關鍵時刻選擇三條不同的命運路線之一
5. **體驗結局：** 根據你的選擇體驗不同的結局

## 📖 劇情結構

### 每個角色的故事包含：

- **第一幕：** 世界如常 - 展示角色在殖民前的日常生活
- **第二幕：** 世界崩塌 - 外來者的到來和信仰的動搖
- **第三幕：** 核心抉擇 - 三條不同的命運路線

### 三種抉擇類型：

每個角色都會面臨三種不同的選擇，代表不同的應對方式：
- **抉擇一：** 反抗或轉變
- **抉擇二：** 逃離或適應
- **抉擇三：** 妥協或犧牲
